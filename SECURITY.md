# Security Policy

## Audit status

This service has **not** undergone an independent security audit. It's deployed as a demo/Testnet-integrated service. Do not point it at real evidence or real personal data without an audit first.

## Reporting a vulnerability

Email **chijiokejoseph20242@gmaill.com** with a description of the issue and reproduction steps. Do not open a public GitHub issue for security vulnerabilities.

You should get an acknowledgement within 5 business days. Once a fix is available, we'll coordinate disclosure timing with you.

## Scope

In scope: this service's extraction, claim-grounding, and citation-verification logic, and its handling of the shared service token. Out of scope: [afterprint-api](https://github.com/Afterprint/afterprint-api) (report those there), the Soroban contracts ([afterprint-contracts](https://github.com/Afterprint/afterprint-contracts)), and third-party APIs (Groq).
